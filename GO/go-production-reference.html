// package main — production readiness guide

Go দিয়ে প্রোডাকশন-গ্রেড ডেভেলপার হওয়ার রোডম্যাপ

Basic syntax থেকে শুরু করে concurrency, error handling ও networking পর্যন্ত 99টি core concept — প্রতিটার concept, purpose, use-case, এবং একজন professional developer-এর নোট সহ। বাম পাশের মেনু থেকে যেকোনো টপিকে সরাসরি চলে যান, বা সার্চ করুন।

Basics

01

Values & Basics

কনসেপ্ট — What it is

Go-তে সবকিছুই একটি ভ্যালু — string, int, bool ইত্যাদি। Go একটি statically typed, compiled ভাষা, তাই টাইপ কম্পাইল টাইমেই ঠিক হয়ে যায়।

উদ্দেশ্য — Purpose

প্রোগ্রামের বেসিক building block বোঝা — লিটারাল ভ্যালু, টাইপ সিস্টেমের ধারণা।

কোথায় ব্যবহার — Where used

প্রতিটা Go প্রোগ্রামের শুরুতেই — println, arithmetic, string concat ইত্যাদিতে।

🎯 Professional Note

Production কোডে কখনোই টাইপ নিয়ে অনুমান করবেন না — fmt.Printf("%T", v) দিয়ে চেক করুন যখন সন্দেহ থাকে। Go interpreted না, তাই runtime এ টাইপ error পাবেন না, কিন্তু compile time এ ধরা পড়বে যা বাগ কমায়।

package main
import "fmt"
func main() {
    fmt.Println("go" + "lang")
    fmt.Println("1+1 =", 1+1)
    fmt.Println(7.0/3.0)
    fmt.Println(true && false, true || false, !true)
}
02

Variables

কনসেপ্ট — What it is

var কীওয়ার্ড দিয়ে explicit ভাবে ভ্যারিয়েবল ডিক্লেয়ার করা যায়, আর := দিয়ে shorthand (type inference সহ) ডিক্লেয়ার+assign একসাথে করা যায়।

উদ্দেশ্য — Purpose

Memory-তে একটা নাম দিয়ে ভ্যালু রাখা এবং পরে সেটা পড়া/পরিবর্তন করা।

কোথায় ব্যবহার — Where used

Function এর ভেতরে := ব্যবহার হয়, package-level এ var লাগবেই (:= শুধু function body-তে চলে)।

🎯 Professional Note

প্রোডাকশনে var ব্লক ব্যবহার করে related ভ্যারিয়েবল গ্রুপ করুন। := বেশি ব্যবহার হয় কারণ ছোট, কিন্তু package-scope এবং zero-value দরকার হলে var ব্যবহার করুন। Unused variable থাকলে Go compile error দেয় — এটা code cleanliness এর জন্য ভালো।

var a = "initial"
var b, c int = 1, 2
var d = true
var e int // zero value 0
f := "apple" // shorthand, শুধু function এর ভেতরে
03

Constants

কনসেপ্ট — What it is

const কীওয়ার্ড দিয়ে এমন ভ্যালু ডিফাইন করা যা compile time এ ফিক্সড থাকে, রানটাইমে পরিবর্তন করা যায় না।

উদ্দেশ্য — Purpose

এমন ভ্যালুর জন্য যা কখনো বদলাবে না — যেমন mathematical constant, config key, status code।

কোথায় ব্যবহার — Where used

String, numeric constant, বিশেষ করে iota দিয়ে enum-এর মতো তৈরি করতে।

🎯 Professional Note

Constants শুধু character, string, boolean, numeric value হতে পারে — struct বা slice const হতে পারে না। numeric constant গুলো untyped থাকে যতক্ষণ না context থেকে টাইপ চাপানো হয়, ফলে খুব বড় precision-এর arithmetic করা যায়।

const s string = "constant"
const n = 500000000
const d = 3e20 / n
func main() {
    fmt.Println(s, n, d)
}
04

Comments

কনসেপ্ট — What it is

// দিয়ে single-line আর /* */ দিয়ে multi-line কমেন্ট লেখা হয়। Package/function/type/const এর ঠিক উপরে লেখা কমেন্ট Go-এর ডকুমেন্টেশন টুল (godoc) ব্যবহার করে।

উদ্দেশ্য — Purpose

কোডের উদ্দেশ্য ব্যাখ্যা করা এবং auto-generated ডকুমেন্টেশন তৈরি করা।

কোথায় ব্যবহার — Where used

প্রতিটা exported function/type এর উপরে (Go convention অনুযায়ী কমেন্ট function/type-এর নাম দিয়েই শুরু হয়)।

🎯 Professional Note

Production Go কোডে exported identifier (Capital letter দিয়ে শুরু) এর উপরে কমেন্ট লেখা প্রায় বাধ্যতামূলক গণ্য করা হয় — golint/staticcheck এটা flag করে। কমেন্ট 'কী করে' না লিখে 'কেন করে' লেখাই ভালো প্র্যাকটিস।

// User represents a registered user in the system.
type User struct {
    Name string
}

/* এটা একটা
   multi-line comment */
func main() {}

Data Types

05

Numbers

কনসেপ্ট — What it is

Go-তে int, int8/16/32/64, uint variants, float32/float64, complex64/128 এর মতো একাধিক numeric টাইপ আছে।

উদ্দেশ্য — Purpose

সঠিক মেমরি সাইজ ও precision অনুযায়ী সংখ্যা সংরক্ষণ করা।

কোথায় ব্যবহার — Where used

Counter, ID, বাফার সাইজ, বৈজ্ঞানিক গণনা ইত্যাদিতে।

🎯 Professional Note

Platform-independent কোডে সাধারণত int ব্যবহার করুন (এটা platform অনুযায়ী 32/64 bit)। Network protocol বা binary file format handle করলে নির্দিষ্ট সাইজ (int32, uint8) ব্যবহার করা উচিত যাতে predictable behavior থাকে।

package main
import "fmt"
func main() {
    var x int = 42
    var y int64 = 1 << 40
    var z uint8 = 255
    fmt.Println(x, y, z)
}
06

Floating-Point Numbers

কনসেপ্ট — What it is

float32 এবং float64 IEEE-754 স্ট্যান্ডার্ড অনুযায়ী দশমিক সংখ্যা রিপ্রেজেন্ট করে। math প্যাকেজ এর সাথে কাজ করার জন্য দরকারি ফাংশন দেয়।

উদ্দেশ্য — Purpose

দশমিক/fractional সংখ্যা নিয়ে হিসাব করা।

কোথায় ব্যবহার — Where used

Financial calculation (সতর্কতার সাথে), scientific computation, graphics ইত্যাদিতে।

🎯 Professional Note

টাকা-পয়সার হিসাবে float ব্যবহার এড়িয়ে চলুন — rounding error হয়। Production এ money represent করতে integer (cents/paisa) অথবা shopspring/decimal-এর মতো লাইব্রেরি ব্যবহার করুন। float তুলনা করার সময় == ব্যবহার না করে epsilon-based comparison করুন।

package main
import ("fmt"; "math")
func main() {
    const f = 3.141592653589793
    fmt.Println(math.Sin(f), math.Pow(f, 2))
}
07

Arithmetic Operators

কনসেপ্ট — What it is

+, -, *, /, % (modulus) এবং bitwise operator (&, |, ^, <<, >>) দিয়ে গাণিতিক অপারেশন করা হয়।

উদ্দেশ্য — Purpose

সংখ্যা নিয়ে যোগ-বিয়োগ-গুণ-ভাগ এবং bit-level manipulation করা।

কোথায় ব্যবহার — Where used

Algorithm, hashing, bit-flag, performance-critical কোডে।

🎯 Professional Note

Integer division-এ ভাগফল truncate হয় (7/2 = 3, float না)। Overflow এর ব্যাপারে সতর্ক থাকুন — fixed-size int টাইপে overflow silently wrap around করে, panic দেয় না।

package main
import "fmt"
func main() {
    fmt.Println(7 / 2)     // 3
    fmt.Println(7 % 2)     // 1
    fmt.Println(1 << 3)    // 8, bitwise shift
    fmt.Println(7 & 3)     // bitwise AND
}
08

Booleans

কনসেপ্ট — What it is

true/false ভ্যালু নেওয়া bool টাইপ, লজিক্যাল অপারেটর &&, ||, ! দিয়ে কম্বাইন করা যায়।

উদ্দেশ্য — Purpose

শর্তসাপেক্ষ decision নেওয়া এবং flag হিসেবে state track করা।

কোথায় ব্যবহার — Where used

if/switch condition, feature flag, validation result-এ।

🎯 Professional Note

Go-তে অন্য ভাষার মতো implicit truthy/falsy নেই — int বা string কে bool হিসেবে ব্যবহার করা যায় না, explicit comparison লিখতে হয়। এটা কোড আরও explicit ও bug-free করে।

package main
import "fmt"
func main() {
    var isActive bool = true
    fmt.Println(isActive && false, isActive || false, !isActive)
}
09

Strings

কনসেপ্ট — What it is

string হলো immutable byte sequence, ডিফল্টভাবে UTF-8 এনকোডেড।

উদ্দেশ্য — Purpose

টেক্সট ডেটা সংরক্ষণ ও প্রসেস করা।

কোথায় ব্যবহার — Where used

প্রায় প্রতিটা অ্যাপ্লিকেশনে — নাম, মেসেজ, JSON, URL ইত্যাদি।

🎯 Professional Note

String immutable, তাই বারবার concatenation (+=) loop এ করলে performance খারাপ হয় — এক্ষেত্রে strings.Builder ব্যবহার করুন। len(s) byte-count দেয়, character count না — মাল্টিবাইট (Bangla, Emoji) স্ট্রিং হ্যান্ডল করতে rune সচেতন থাকতে হবে।

package main
import "fmt"
func main() {
    s := "সুপ্রভাত, world"
    fmt.Println(len(s))      // byte length
    fmt.Println(s[0])        // byte value
}
10

Strings and Runes

কনসেপ্ট — What it is

Go string আসলে byte slice; rune হলো একটা int32 যা একটা Unicode code point represent করে। for range দিয়ে string iterate করলে rune পাওয়া যায়, byte না।

উদ্দেশ্য — Purpose

Multi-byte/Unicode ক্যারেক্টার (যেমন বাংলা, ইমোজি) সঠিকভাবে হ্যান্ডেল করা।

কোথায় ব্যবহার — Where used

Internationalization (i18n), text processing, string reversal-এর মতো কাজে।

🎯 Professional Note

byte index দিয়ে সরাসরি s[i] করলে multi-byte ক্যারেক্টার ভেঙে যেতে পারে। সবসময় []rune(s) এ কনভার্ট করে বা utf8 প্যাকেজ ব্যবহার করে Unicode-safe ভাবে string manipulate করুন — এটা production i18n বাগের সবচেয়ে বড় কারণ।

package main
import "fmt"
func main() {
    const s = "বাংলা"
    for i, r := range s {
        fmt.Printf("%d:%c ", i, r)
    }
    runes := []rune(s)
    fmt.Println("\nrune count:", len(runes))
}
11

Runes

কনসেপ্ট — What it is

rune হলো int32-এর alias, একটা single Unicode code point ধরে রাখে। '' (single quote) দিয়ে rune literal লেখা হয়।

উদ্দেশ্য — Purpose

একক character নিয়ে কাজ করা যখন byte যথেষ্ট না (multi-byte ক্যারেক্টার)।

কোথায় ব্যবহার — Where used

Character validation, parsing, custom tokenizer লেখায়।

🎯 Professional Note

rune আর byte গুলিয়ে ফেলা কমন ভুল — ASCII এর জন্য দুটো এক হলেও non-ASCII এর জন্য না। unicode প্যাকেজের IsLetter, IsDigit ইত্যাদি rune এর উপর কাজ করে।

package main
import ("fmt"; "unicode")
func main() {
    r := 'A'
    fmt.Println(r, string(r), unicode.IsUpper(r))
}
12

Strings Package

কনসেপ্ট — What it is

strings প্যাকেজ string manipulation-এর জন্য অনেক ready-made ফাংশন দেয় — Contains, Split, Join, ToUpper, TrimSpace ইত্যাদি।

উদ্দেশ্য — Purpose

কমন string অপারেশনের জন্য নিজে ফাংশন না লিখে standard library ব্যবহার করা।

কোথায় ব্যবহার — Where used

Input validation, parsing, formatting — প্রায় সব জায়গায়।

🎯 Professional Note

চাকা পুনরাবিষ্কার না করে strings প্যাকেজ ভালোভাবে জানুন — এটা performance-optimized এবং well-tested। strings.Builder বড় string তৈরিতে concatenation থেকে অনেক দ্রুত।

package main
import ("fmt"; "strings")
func main() {
    fmt.Println(strings.Contains("test", "es"))
    fmt.Println(strings.Split("a,b,c", ","))
    fmt.Println(strings.ToUpper("golang"))
    var sb strings.Builder
    sb.WriteString("hello ")
    sb.WriteString("world")
    fmt.Println(sb.String())
}
13

String Functions

কনসেপ্ট — What it is

strings প্যাকেজের বাইরেও strconv (parsing/formatting) এবং bytes প্যাকেজ string/byte-level ফাংশন দেয়।

উদ্দেশ্য — Purpose

টেক্সট প্রসেসিং, ভ্যালিডেশন, ট্রান্সফরমেশনের জন্য বিভিন্ন utility ব্যবহার করা।

কোথায় ব্যবহার — Where used

Log parsing, CSV processing, input sanitization এ।

🎯 Professional Note

strings.Fields() whitespace-split করে (Split(" ") থেকে বেশি robust কারণ multiple space handle করে)। HasPrefix/HasSuffix ব্যবহার করুন substring index নিজে বের করার বদলে।

package main
import ("fmt"; "strings")
func main() {
    fmt.Println(strings.Fields("  foo  bar  baz "))
    fmt.Println(strings.HasPrefix("golang", "go"))
    fmt.Println(strings.Replace("oink oink", "oink", "moo", -1))
}
14

String Formatting

কনসেপ্ট — What it is

fmt প্যাকেজ দিয়ে Printf/Sprintf verb (%d, %s, %v, %T, %+v ইত্যাদি) ব্যবহার করে ফরম্যাটেড আউটপুট তৈরি করা হয়।

উদ্দেশ্য — Purpose

ভ্যালুকে readable/structured string এ কনভার্ট করে দেখানো বা লগ করা।

কোথায় ব্যবহার — Where used

Logging, error message, CLI output, debug printing।

🎯 Professional Note

%v জেনেরিক ভ্যালু, %+v struct এর field name সহ দেখায়, %#v Go-syntax representation দেয় — debugging-এ %+v বা %#v খুব কাজে লাগে। Sprintf দিয়ে string বানিয়ে error বা log এ পাঠানো common pattern।

package main
import "fmt"
type point struct{ x, y int }
func main() {
    p := point{1, 2}
    fmt.Printf("%v\n", p)
    fmt.Printf("%+v\n", p)
    fmt.Printf("%T\n", p)
    s := fmt.Sprintf("%d apples", 5)
    fmt.Println(s)
}

Comparison

কনসেপ্ট — What it is

উদ্দেশ্য — Purpose

দুটো ভ্যালু সমান কিনা বা কার relative order বড়/ছোট তা যাচাই করা।

কোথায় ব্যবহার — Where used

Sorting, conditional logic, validation, deduplication এ।

🎯 Professional Note

Slice, map, function টাইপ সরাসরি == দিয়ে comparable না (nil check বাদে) — কম্পাইল এরর দেয়। এগুলোর জন্য reflect.DeepEqual অথবা ম্যানুয়াল লুপ লাগবে। Float comparison-এ precision issue মাথায় রাখুন।

Zero Values

কনসেপ্ট — What it is

Go-তে ডিক্লেয়ার করা মাত্র প্রতিটা ভ্যারিয়েবল একটা predictable zero value পায় — int→0, string→"", bool→false, pointer/slice/map/interface→nil।

উদ্দেশ্য — Purpose

Explicitly initialize না করলেও ভ্যারিয়েবল সবসময় একটা valid, well-defined state এ থাকে (garbage value নয়)।

কোথায় ব্যবহার — Where used

Struct initialization, default config value, uninitialized field হ্যান্ডেল করায়।

🎯 Professional Note

Zero value নিয়ে চিন্তা করে struct design করলে কোড অনেক safer হয় — যেমন sync.Mutex এর zero value ব্যবহারযোগ্য (unlocked)। কিন্তু nil map-এ write করলে panic হয় (read করা যায়, write না) — এটা একটা কমন রানটাইম বাগ।

package main
import "fmt"
func main() {
    var i int
    var s string
    var m map[string]int
    fmt.Println(i, s == "", m == nil)
    // m["x"] = 1 // panic: assignment to entry in nil map
}

Type Conversion

কনসেপ্ট — What it is

উদ্দেশ্য — Purpose

একটা টাইপের ভ্যালু আরেকটা টাইপ যেখানে দরকার সেখানে ব্যবহার করা।

কোথায় ব্যবহার — Where used

int↔float conversion, string↔[]byte, custom type ↔ underlying type।

🎯 Professional Note

int থেকে int8/int32 কনভার্ট করলে overflow হলে silently truncate হয় (error দেয় না) — বড় সংখ্যা ছোট টাইপে ঢোকানোর সময় সতর্ক থাকুন। string(int) করলে সেই int কে rune/character হিসেবে ইন্টারপ্রেট করে, সংখ্যার string রূপ পেতে strconv.Itoa লাগবে — এটা প্রায়ই বিভ্রান্তির কারণ হয়।

package main
import "fmt"
func main() {

    f := float64(i)
    u := uint(f)
    fmt.Println(i, f, u)
    fmt.Println(string(rune(i))) // "A", not "65"
}

Conditionals: Switch

কনসেপ্ট — What it is

উদ্দেশ্য — Purpose

একাধিক সম্ভাব্য value/condition এর মধ্যে branching readable ভাবে করা।

কোথায় ব্যবহার — Where used

State machine, HTTP method routing, type-based branching (type switch)।

🎯 Professional Note

Go-তে C/Java-এর মতো fallthrough হয় না বলে ভুলে break না দেওয়ার বাগ হয় না — এটা নিরাপদ ডিফল্ট। type switch (switch v := i.(type)) দিয়ে interface{} এর আসল টাইপ বের করা production কোডে খুবই কমন।

package main
import "fmt"
func main() {
    i := 2
    switch i {
    case 1:
        fmt.Println("one")
    case 2, 3:
        fmt.Println("two or three")
    default:
        fmt.Println("other")
    }
    switch v := interface{}(true).(type) {
    case bool:
        fmt.Println("bool", v)
    default:
        fmt.Println("unknown")
    }
}

For / For Loops

কনসেপ্ট — What it is

Go-তে একমাত্র লুপিং কনস্ট্রাক্ট হলো for — এটাই while এর কাজও করে, এবং infinite loop (for {}) ও সাপোর্ট করে।

উদ্দেশ্য — Purpose

কোনো ব্লক বারবার execute করা।

কোথায় ব্যবহার — Where used

Iteration, retry logic, polling, batch processing।

🎯 Professional Note

for i, for cond {}, for {} — এই তিন ফর্মই মনে রাখুন। break/continue label সহ ব্যবহার করে nested loop থেকে বের হওয়া যায় (outer: for {...}), যা জটিল nested loop control-এ দরকার হয়।

package main
import "fmt"
func main() {
    i := 1
    for i <= 3 { fmt.Println(i); i = i + 1 }
    for j := 0; j < 3; j++ { fmt.Println(j) }
outer:
    for i := 0; i < 3; i++ {
        for j := 0; j < 3; j++ {
            if j == 1 { continue outer }
            fmt.Println(i, j)
        }
    }
}

কনসেপ্ট — What it is

উদ্দেশ্য — Purpose

Collection-এর প্রতিটা উপাদান নিয়ে কাজ করা এক ইউনিফর্ম সিনট্যাক্সে।

কোথায় ব্যবহার — Where used

Data processing, transformation, aggregation এর প্রায় সব জায়গায়।

🎯 Professional Note

Loop ভ্যারিয়েবল আগে (Go 1.21-এর আগে) প্রতি ইটারেশনে reuse হতো — closure-এ ক্যাপচার করলে ভুল ভ্যালু পাওয়া common বাগ ছিল। Go 1.22+ এ এটা fix হয়েছে (প্রতি iteration-এ নতুন variable), তবে পুরনো কোড/version নিয়ে কাজ করলে এই ইতিহাস জানা জরুরি।

    fmt.Println("sum:", sum)

    kvs := map[string]string{"a": "apple"}
    for k, v := range kvs { fmt.Println(k, "->", v) }

Slices

কনসেপ্ট — What it is

slice হলো array-এর উপর dynamic, resizable একটা view — এটার একটা pointer, length, capacity থাকে। make([]T, len, cap) দিয়ে তৈরি হয়, append দিয়ে বাড়ানো যায়।

উদ্দেশ্য — Purpose

Dynamic-size list/collection নিয়ে কাজ করা।

কোথায় ব্যবহার — Where used

প্রায় সব জায়গায় — API response, DB row, in-memory list।

🎯 Professional Note

append() মাঝে মাঝে নতুন underlying array allocate করে (যখন capacity ফুরিয়ে যায়), তাই append-এর রিটার্ন ভ্যালু সবসময় আসল ভ্যারিয়েবলে assign করতে হবে (s = append(s, x))। দুটো slice একই underlying array শেয়ার করতে পারে — একটাতে পরিবর্তন করলে অন্যটাতেও reflect করতে পারে, এটা subtle বাগের উৎস।

package main
import "fmt"
func main() {
    s := make([]string, 3)
    s[0] = "a"
    s = append(s, "d", "e")
    c := make([]string, len(s))
    copy(c, s)
    l := s[2:5] // slicing
    fmt.Println(s, c, l, cap(s))
}

Maps

কনসেপ্ট — What it is

উদ্দেশ্য — Purpose

Key দিয়ে দ্রুত value lookup, associative data রাখা।

কোথায় ব্যবহার — Where used

Caching, counting, config storage, lookup table-এ।

🎯 Professional Note

Map iteration order guaranteed random — একই map বারবার range করলে ভিন্ন order আসতে পারে, order দরকার হলে key গুলো আলাদা slice-এ রেখে সর্ট করুন। comma-ok idiom (v, ok := m[k]) দিয়ে key exist করে কিনা zero-value থেকে আলাদা করে বুঝা যায় — এটা না করলে missing key আর zero-value গুলিয়ে ফেলার বাগ হয়।

package main
import "fmt"

    m["k1"] = 7
    v, ok := m["k2"]
    fmt.Println(v, ok) // 0 false
    delete(m, "k1")
    fmt.Println(m)
}

Functions

Multiple Return Values

কনসেপ্ট — What it is

উদ্দেশ্য — Purpose

একটা ভ্যালুর সাথে error বা ok flag রিটার্ন করা, tuple-এর দরকার এড়ানো।

কোথায় ব্যবহার — Where used

(result, error) প্যাটার্ন — Go-এর প্রায় সব standard library function এই প্যাটার্ন অনুসরণ করে।

🎯 Professional Note

(value, error) রিটার্ন প্যাটার্ন Go-এর error handling philosophy-এর মূল ভিত্তি — exception এর বদলে explicit error check। _ ব্যবহার করে অপ্রয়োজনীয় রিটার্ন ভ্যালু discard করা যায়, কিন্তু error কখনো discard করা উচিত না production কোডে।

package main
import "fmt"
func vals() (int, int) { return 3, 7 }
func divide(a, b int) (int, error) {
    if b == 0 { return 0, fmt.Errorf("division by zero") }
    return a / b, nil
}
func main() {
    a, b := vals()
    fmt.Println(a, b)
    r, err := divide(10, 0)
    fmt.Println(r, err)
}

কনসেপ্ট — What it is

উদ্দেশ্য — Purpose

একই function কে flexible সংখ্যক argument দিয়ে call করার সুবিধা দেওয়া।

কোথায় ব্যবহার — Where used

🎯 Professional Note

existing slice কে ...-suffix দিয়ে variadic function এ পাস করা যায় (nums...) — এটা না জানলে অনেকে slice কে element-by-element লুপ করে পাঠান, যেটা অপ্রয়োজনীয়।

Closures

কনসেপ্ট — What it is

Closure হলো এমন একটা anonymous function যা তার বাইরের scope-এর ভ্যারিয়েবল ক্যাপচার করে রাখে এবং পরবর্তীতে সেই state মনে রাখে।

উদ্দেশ্য — Purpose

State encapsulate করে function-এর মধ্যে রাখা, function factory তৈরি করা।

কোথায় ব্যবহার — Where used

Counter, middleware, callback, event handler-এ।

🎯 Professional Note

প্রতিটা closure call তার নিজস্ব ক্যাপচার করা variable এর reference রাখে (shared না, যদি না একই enclosing scope থেকে একাধিক closure একই variable শেয়ার করে) — goroutine-এ loop variable ক্যাপচার করার সময় এটা নিয়ে সতর্ক থাকা জরুরি।

package main
import "fmt"
func intSeq() func() int {
    i := 0
    return func() int { i++; return i }
}
func main() {
    nextInt := intSeq()
    fmt.Println(nextInt(), nextInt(), nextInt())

Recursion

কনসেপ্ট — What it is

একটা function নিজেকে নিজে call করে — একটা base case না থাকলে infinite loop এ পড়বে।

উদ্দেশ্য — Purpose

সমস্যাকে ছোট ছোট একই ধরনের সাব-প্রবলেমে ভেঙে সমাধান করা।

কোথায় ব্যবহার — Where used

Tree/graph traversal, factorial/fibonacci, divide-and-conquer algorithm।

🎯 Professional Note

Go compiler tail-call optimization করে না (অন্য কিছু ভাষার মতো), তাই খুব deep recursion stack overflow করতে পারে — বড় ডেটাসেটে recursion এর বদলে iterative approach বিবেচনা করুন।

package main
import "fmt"
func fact(n int) int {
    if n == 0 { return 1 }
    return n * fact(n-1)
}
func main() { fmt.Println(fact(7)) }

কনসেপ্ট — What it is

উদ্দেশ্য — Purpose

কোথায় ব্যবহার — Where used

Callback, strategy pattern, middleware chaining, sort.Slice এর comparator।

🎯 Professional Note

Function টাইপ signature (func(int) int) নামিয়ে দিলে কোড readability বাড়ে। Higher-order function বেশি ব্যবহার করলে কোড elegant হয় কিন্তু over-abstraction এড়িয়ে চলুন, বিশেষত junior team-মেম্বার থাকলে।

package main
import "fmt"

func main() {
    double := func(x int) int { return x * 2 }

Pointers

কনসেপ্ট — What it is

Pointer একটা মেমরি অ্যাড্রেস ধরে রাখে। &v দিয়ে address নেওয়া, *p দিয়ে dereference করে ভ্যালু access করা হয়।

উদ্দেশ্য — Purpose

একটা ভ্যালুর কপি না করে সরাসরি সেই মেমরিতে reference দিয়ে পরিবর্তন করা।

কোথায় ব্যবহার — Where used

বড় struct পাস করা (কপি এড়াতে), function এর ভেতর থেকে caller-এর ভ্যালু পরিবর্তন করা।

🎯 Professional Note

Go-তে pointer arithmetic নেই (C-এর মতো), যা memory-safety বাড়ায়। nil pointer dereference করলে runtime panic হয় — production কোডে pointer ব্যবহারের আগে nil check করা জরুরি অভ্যাস।

package main
import "fmt"
func zeroval(ival int) { ival = 0 }
func zeroptr(iptr *int) { *iptr = 0 }
func main() {
    i := 1
    zeroval(i)
    fmt.Println(i) // 1, unchanged
    zeroptr(&i)
    fmt.Println(i) // 0, changed
}

কনসেপ্ট — What it is

উদ্দেশ্য — Purpose

সম্পর্কিত ডেটাকে একটা logical unit হিসেবে গ্রুপ করা।

কোথায় ব্যবহার — Where used

Domain model (User, Order), config struct, DTO/API payload-এ।

🎯 Professional Note

Struct literal-এ field name উল্লেখ করে initialize করা (point{X: 1, Y: 2}) positional initialization (point{1, 2}) থেকে নিরাপদ — কারণ পরে field অর্ডার বদলালেও কোড ভাঙবে না। JSON marshal/unmarshal-এর জন্য struct tag (`json:"name"`) ব্যবহার খুবই common।

Methods

কনসেপ্ট — What it is

Method হলো একটা receiver (struct বা যেকোনো named type) সহ function — value receiver (v Type) বা pointer receiver (v *Type) হতে পারে।

উদ্দেশ্য — Purpose

একটা টাইপের সাথে behavior/function সংযুক্ত করা — object-oriented স্টাইল আচরণ পাওয়া।

কোথায় ব্যবহার — Where used

Domain logic (order.Total(), user.FullName()), business rule encapsulation-এ।

🎯 Professional Note

Struct-এর ভেতরের state পরিবর্তন করতে হলে pointer receiver ব্যবহার করতে হবে, নাহলে কপির উপর পরিবর্তন হবে যা caller দেখতে পাবে না। একটা টাইপের সব method একই ধরনের receiver (সব value বা সব pointer) ব্যবহার করা convention হিসেবে ভালো।

package main
import "fmt"
type rect struct{ width, height int }
func (r *rect) scale(f int) { r.width *= f; r.height *= f }
func (r rect) area() int { return r.width * r.height }
func main() {
    r := rect{width: 10, height: 5}
    r.scale(2)
    fmt.Println(r.area())
}

Struct Embedding

কনসেপ্ট — What it is

একটা struct এর ভেতর আরেকটা struct কে নাম ছাড়া (anonymous field) embed করলে বাইরের struct সরাসরি ভেতরের struct-এর field ও method access করতে পারে।

উদ্দেশ্য — Purpose

Composition এর মাধ্যমে code reuse করা (Go-তে inheritance নেই, তার বদলে embedding ব্যবহার হয়)।

কোথায় ব্যবহার — Where used

Base struct-এর common behavior extend করা, interface satisfy করার জন্য।

🎯 Professional Note

Go-তে 'is-a' inheritance নেই, শুধু composition আছে — এটা design mindset-এ পার্থক্য তৈরি করে ('composition over inheritance' Go-তে built-in idiom)। Embedded টাইপের method override করলে outer struct-এর নিজের method প্রায়োরিটি পায়।

package main
import "fmt"
type base struct{ name string }
func (b base) describe() string { return "I am " + b.name }
type employee struct {
    base
    role string
}
func main() {
    e := employee{base: base{name: "Karim"}, role: "Engineer"}
    fmt.Println(e.describe(), e.name, e.role)
}

Generics

কনসেপ্ট — What it is

Go 1.18+ থেকে generics এসেছে — function/type-এ type parameter ([T any]) দিয়ে একই কোড একাধিক টাইপে reuse করা যায়।

উদ্দেশ্য — Purpose

টাইপ-নিরপেক্ষ (type-safe) reusable কোড লেখা, code duplication এড়ানো।

কোথায় ব্যবহার — Where used

Generic data structure (Stack[T], LinkedList[T]), utility function (Map, Filter, Reduce)।

🎯 Professional Note

Generics আসার আগে Go-তে interface{} দিয়ে টাইপ-agnostic কোড লেখা হতো, যা runtime এ type assertion দরকার করত এবং compile-time safety হারাতো — generics এখন compile-time type safety সহ একই সুবিধা দেয়। Overuse এড়িয়ে চলুন — যেখানে সাধারণ কোডই যথেষ্ট, সেখানে অহেতুক generic বানাবেন না, এতে readability কমে।

package main
import "fmt"
type Number interface{ int64 | float64 }
func SumNumbers[T Number](nums []T) T {
    var sum T
    for _, n := range nums { sum += n }
    return sum
}
func main() {
    fmt.Println(SumNumbers([]int64{1, 2, 3}))
    fmt.Println(SumNumbers([]float64{1.1, 2.2}))
}

Range over Iterators

কনসেপ্ট — What it is

Go 1.23+ এ range এখন একটা function (iterator, func(yield func(K, V) bool)) এর উপরও কাজ করতে পারে, যাকে বলে range-over-func।

উদ্দেশ্য — Purpose

কাস্টম sequence/collection কে built-in slice/map এর মতো idiomatic ভাবে iterate করার সুবিধা দেওয়া।

কোথায় ব্যবহার — Where used

Custom container টাইপ, lazy evaluation দরকার এমন data pipeline-এ।

🎯 Professional Note

এটা তুলনামূলক নতুন feature (Go 1.23) — production এ ব্যবহার করার আগে আপনার deployment এর Go version নিশ্চিত করুন। iter প্যাকেজে Seq/Seq2 টাইপ ডিফাইন করা আছে যা standard library gradually adopt করছে।

package main
import "fmt"
func Count(start, end int) func(func(int) bool) {
    return func(yield func(int) bool) {
        for i := start; i <= end; i++ {
            if !yield(i) { return }
        }
    }
}
func main() {
    for n := range Count(1, 3) { fmt.Println(n) }
}

Interfaces

কনসেপ্ট — What it is

Interface হলো method signature-এর একটা set। কোনো টাইপ যদি interface-এর সব method implement করে, সে implicitly সেই interface satisfy করে — আলাদা করে 'implements' লেখার দরকার নেই।

উদ্দেশ্য — Purpose

Behavior-ভিত্তিক abstraction তৈরি করা, concrete টাইপ থেকে decouple করা।

কোথায় ব্যবহার — Where used

Dependency injection, mocking/testing, plugin architecture, polymorphism।

🎯 Professional Note

Go interface implicit — এটা Java/C# থেকে বড় পার্থক্য এবং এটাই duck-typing এর মতো flexibility দেয়। ছোট interface লেখা Go-এর idiom ('accept interfaces, return structs') — যত ছোট interface, তত বেশি reusable ও testable কোড।

package main

    area() float64
    perim() float64

func (c circle) area() float64 { return math.Pi * c.radius * c.radius }
func (c circle) perim() float64 { return 2 * math.Pi * c.radius }
func measure(g geometry) { fmt.Println(g.area(), g.perim()) }
func main() { measure(circle{radius: 5}) }

Stringers

কনসেপ্ট — What it is

উদ্দেশ্য — Purpose

একটা কাস্টম টাইপকে কিভাবে string হিসেবে প্রিন্ট/লগ করা হবে তা নিয়ন্ত্রণ করা।

কোথায় ব্যবহার — Where used

Domain টাইপের readable log output, debug-friendly toString-এর মতো ব্যবহার।

🎯 Professional Note

Error টাইপ, enum-এর মতো custom টাইপে String() implement করা প্রায় standard practice — এতে fmt.Println(myEnum) সরাসরি readable আউটপুট দেয়, integer value না দেখিয়ে।

Type Assertion

কনসেপ্ট — What it is

i.(T) সিনট্যাক্স দিয়ে একটা interface ভ্যালুর আসল underlying concrete টাইপ চেক/extract করা হয়। comma-ok ফর্ম (v, ok := i.(T)) নিরাপদ, না হলে panic হতে পারে।

উদ্দেশ্য — Purpose

একটা interface{} বা interface ভ্যালু থেকে নির্দিষ্ট concrete টাইপ বের করা।

কোথায় ব্যবহার — Where used

JSON unmarshal করা interface{} data নিয়ে কাজ করা, error টাইপ চেক করা।

🎯 Professional Note

comma-ok ছাড়া assertion (v := i.(T)) টাইপ না মিললে panic করে — production কোডে সবসময় ok ভ্যালু চেক করুন যদি নিশ্চিত না থাকেন। errors.As() ব্যবহার করা error টাইপ assertion-এর জন্য বেশি idiomatic (wrapped error handle করে)।

package main
import "fmt"
func main() {
    var i interface{} = "hello"
    s, ok := i.(string)
    fmt.Println(s, ok)
    f, ok := i.(float64)
    fmt.Println(f, ok) // 0 false, no panic
}

Type Definitions

কনসেপ্ট — What it is

type কীওয়ার্ড দিয়ে একটা নতুন named টাইপ ডিফাইন করা যায় — সেটা কোনো existing টাইপের উপর ভিত্তি করে (type Celsius float64) অথবা struct/interface হতে পারে।

উদ্দেশ্য — Purpose

কোথায় ব্যবহার — Where used

package main

Errors

কনসেপ্ট — What it is

error হলো একটা built-in interface (Error() string method সহ)। Go exception ব্যবহার করে না — function গুলো error কে সাধারণ রিটার্ন ভ্যালু হিসেবে দেয়, caller explicit if err != nil দিয়ে চেক করে।

উদ্দেশ্য — Purpose

কোনো অপারেশন ব্যর্থ হলে সেটা caller কে জানানো, explicit ও predictable error handling।

কোথায় ব্যবহার — Where used

File I/O, network call, parsing, validation — যেকোনো fallible অপারেশনে।

🎯 Professional Note

Error-কে ignore না করে সবসময় হ্যান্ডেল করুন (linter এটা enforce করতে সাহায্য করে)। errors.New বা fmt.Errorf("...: %w", err) দিয়ে wrapping করলে error-এর context হারায় না — production debugging-এ এই context অমূল্য।

package main
import ("errors"; "fmt")
func mayFail(arg int) (int, error) {
    if arg == 42 {
        return -1, errors.New("can't work with 42")
    }
    return arg + 3, nil
}
func main() {
    if r, err := mayFail(42); err != nil {
        fmt.Println("error:", err)
    } else {
        fmt.Println("result:", r)
    }
}

Custom Errors

কনসেপ্ট — What it is

নিজের struct-এ error interface (Error() string method) implement করে domain-specific, structured error তৈরি করা যায়, যাতে extra context/field রাখা যায়।

উদ্দেশ্য — Purpose

শুধু একটা message না, error-এর সাথে structured metadata (error code, field name ইত্যাদি) বহন করা।

কোথায় ব্যবহার — Where used

API error response, validation error (যেখানে কোন field ভুল তা জানানো দরকার), retryable vs non-retryable error আলাদা করায়।

🎯 Professional Note

errors.Is() আর errors.As() দিয়ে wrapped custom error চেক করা Go 1.13+ এর idiomatic উপায় — sentinel error (var ErrNotFound = errors.New(...)) আর custom error type দুটোরই নিজস্ব use-case আছে, প্রয়োজন বুঝে বেছে নিন।

package main
import "fmt"
type ValidationError struct {
    Field string
    Msg   string
}
func (e *ValidationError) Error() string {
    return fmt.Sprintf("%s: %s", e.Field, e.Msg)
}
func main() {
    var err error = &ValidationError{Field: "email", Msg: "invalid format"}
    fmt.Println(err)
}

Panic

কনসেপ্ট — What it is

panic হলো একটা runtime অবস্থা যেখানে প্রোগ্রাম immediately স্বাভাবিক execution বন্ধ করে stack unwind করতে থাকে — recover না করলে প্রোগ্রাম crash করে।

উদ্দেশ্য — Purpose

এমন unrecoverable/unexpected অবস্থার জন্য যা থেকে সঠিকভাবে চলা সম্ভব না (যেমন programmer bug, missing dependency)।

কোথায় ব্যবহার — Where used

সাধারণত ব্যবহার এড়ানো হয়; মূলত library init, invariant violation ধরায় ব্যবহৃত হয়।

🎯 Professional Note

Production Go কোডে panic ব্যবহার করে normal error flow control করা anti-pattern — expected error-এর জন্য সবসময় error রিটার্ন ভ্যালু ব্যবহার করুন, panic শুধু সত্যিকারের exceptional/unrecoverable অবস্থার জন্য রাখুন।

package main
import "fmt"
func main() {
    defer fmt.Println("deferred still runs")
    panic("something went horribly wrong")
}

Defer

কনসেপ্ট — What it is

defer কোনো function call কে বর্তমান function রিটার্ন হওয়ার ঠিক আগ পর্যন্ত পিছিয়ে দেয়। একাধিক defer LIFO (last-in-first-out) অর্ডারে execute হয়।

উদ্দেশ্য — Purpose

Cleanup/resource-release লজিক (file close, lock unlock) কে allocation-এর কাছাকাছি লিখে কোড readable ও leak-proof রাখা।

কোথায় ব্যবহার — Where used

file.Close(), mutex.Unlock(), database connection release, panic-এর পরেও নিশ্চিতভাবে cleanup চালানো।

🎯 Professional Note

defer এর argument defer statement execute হওয়ার সময়ই evaluate হয়, function আসলে call হওয়ার সময় না — এটা একটা subtle কিন্তু গুরুত্বপূর্ণ ব্যাপার (defer fmt.Println(i) এ i-এর তখনকার ভ্যালু ক্যাপচার হয়)। Loop-এর ভেতরে defer ব্যবহার করলে সব defer function-টার শেষ পর্যন্ত জমা থাকে — মেমরি লিক এড়াতে সতর্ক থাকুন।

package main
import "fmt"
func main() {
    defer fmt.Println("1st deferred, prints last")
    defer fmt.Println("2nd deferred, prints first")
    fmt.Println("main body")
}

Recover

কনসেপ্ট — What it is

recover() একটা built-in function যা শুধু defer করা function-এর ভেতরে কাজ করে — এটা একটা চলমান panic ধরে ফেলে এবং প্রোগ্রামকে normal execution ফেরত দেয়।

উদ্দেশ্য — Purpose

একটা goroutine/function-এর panic হলেও পুরো প্রোগ্রাম crash হওয়া থেকে বাঁচানো।

কোথায় ব্যবহার — Where used

HTTP server middleware (per-request panic recovery), worker goroutine-এ crash isolate করা।

🎯 Professional Note

recover() শুধু defer function-এর সরাসরি ভেতরে কাজ করে, nested function call থেকে না — এই সীমাবদ্ধতা না জানলে recover কাজ না করার বাগ হয়। প্রতিটা production HTTP handler-এ সাধারণত একটা recovery middleware থাকে যাতে একটা request-এর panic গোটা সার্ভার নামিয়ে না দেয়।

package main
import "fmt"
func mayPanic() { panic("a problem") }
func safelyDo() {
    defer func() {
        if r := recover(); r != nil {
            fmt.Println("recovered from:", r)
        }
    }()
    mayPanic()
    fmt.Println("this line never runs")
}
func main() { safelyDo(); fmt.Println("program continues") }

Goroutines

কনসেপ্ট — What it is

go কীওয়ার্ড দিয়ে একটা function কে lightweight, concurrently-running goroutine হিসেবে launch করা হয় — এগুলো OS thread না, Go runtime দ্বারা multiplex করা হয়।

উদ্দেশ্য — Purpose

একই সাথে একাধিক কাজ concurrently চালানো, কম overhead-এ।

কোথায় ব্যবহার — Where used

Parallel HTTP request, background job, concurrent data processing।

🎯 Professional Note

main() ফেরত এলে সব চলমান goroutine সাথে সাথে মারা যায়, তাই sync.WaitGroup বা channel দিয়ে সিঙ্ক্রোনাইজ করা জরুরি (নাহলে goroutine শেষ হওয়ার আগেই main বেরিয়ে যেতে পারে)। হাজার হাজার goroutine চালানো সাধারণ ব্যাপার — এদের memory footprint খুবই ছোট (few KB stack, growable)।

package main
import ("fmt"; "sync")
func f(id int, wg *sync.WaitGroup) {
    defer wg.Done()
    fmt.Println("worker", id, "done")
}
func main() {
    var wg sync.WaitGroup
    for i := 0; i < 3; i++ {
        wg.Add(1)
        go f(i, &wg)
    }
    wg.Wait()
}

Channels

কনসেপ্ট — What it is

Channel হলো goroutine-দের মধ্যে টাইপ-সচেতনভাবে ভ্যালু পাঠানো-নেওয়ার একটা pipe — make(chan T) দিয়ে তৈরি হয়, <- operator দিয়ে send/receive করা হয়।

উদ্দেশ্য — Purpose

Goroutine-দের মধ্যে নিরাপদে ডেটা শেয়ার/সিঙ্ক্রোনাইজ করা ('shared memory দিয়ে communicate না করে, communicate করে memory শেয়ার করা' — Go-এর দর্শন)।

কোথায় ব্যবহার — Where used

Producer-consumer pattern, pipeline, result aggregation।

🎯 Professional Note

Unbuffered channel-এ send ততক্ষণ block হয় যতক্ষণ না কেউ receive করে — এটা natural synchronization দেয় কিন্তু ভুলভাবে ব্যবহার করলে deadlock হতে পারে (কেউ receive না করলে send চিরতরে ব্লক থাকবে)।

package main
import "fmt"
func main() {
    messages := make(chan string)
    go func() { messages <- "ping" }()
    msg := <-messages
    fmt.Println(msg)
}

Channel Buffering

কনসেপ্ট — What it is

make(chan T, N) দিয়ে buffered channel তৈরি করা হয় — buffer ভর্তি না হওয়া পর্যন্ত send block হয় না।

উদ্দেশ্য — Purpose

Sender ও receiver-কে সাময়িকভাবে decouple করা, throughput বাড়ানো।

কোথায় ব্যবহার — Where used

Rate-limited queue, batching, producer-consumer যেখানে সামান্য lag acceptable।

🎯 Professional Note

Buffer size ভুলভাবে বড় করলে backpressure হারিয়ে যায় (system overload হলেও সেটা দেরিতে ধরা পড়ে) — buffer size একটা deliberate capacity-planning সিদ্ধান্ত, শুধু 'error এড়ানোর জন্য' বড় করা উচিত না।

package main
import "fmt"
func main() {
    messages := make(chan string, 2)
    messages <- "buffered"
    messages <- "channel"
    fmt.Println(<-messages, <-messages)
}

Channel Synchronization

কনসেপ্ট — What it is

Channel শুধু ডেটা পাঠানোর জন্যই না, goroutine-দের মধ্যে সিঙ্ক্রোনাইজেশনের (একটা কাজ শেষ হয়েছে কি না জানানো) জন্যও ব্যবহার করা যায় — এমনকি খালি struct{} channel দিয়েও।

উদ্দেশ্য — Purpose

একটা goroutine অপেক্ষা করা যতক্ষণ না আরেকটা goroutine তার কাজ শেষ করে।

কোথায় ব্যবহার — Where used

Task completion signal, done channel প্যাটার্ন, graceful shutdown।

🎯 Professional Note

খালি struct{} (chan struct{}) সিগন্যালিং-এর জন্য bool বা int channel থেকে ভালো কারণ এটা zero memory নেয় এবং intent স্পষ্ট করে (ভ্যালু গুরুত্বপূর্ণ না, শুধু event ঘটেছে কিনা সেটাই গুরুত্বপূর্ণ)।

package main
import ("fmt"; "time")
func worker(done chan bool) {
    time.Sleep(time.Second)
    fmt.Println("working done")
    done <- true
}
func main() {
    done := make(chan bool, 1)
    go worker(done)
    <-done
}

Channel Directions

কনসেপ্ট — What it is

Function signature-এ channel টাইপকে send-only (chan<- T) বা receive-only (<-chan T) হিসেবে নির্দিষ্ট করা যায়, যা bidirectional channel থেকে বেশি restrictive।

উদ্দেশ্য — Purpose

Compile-time এ নিশ্চিত করা কোন function channel দিয়ে শুধু পাঠাবে বা শুধু পড়বে, ভুল ব্যবহার আটকানো।

কোথায় ব্যবহার — Where used

Producer/consumer function সিগনেচার ডিজাইন করা, pipeline stage আলাদা করা।

🎯 Professional Note

এটা শুধু documentation না — কম্পাইলার এটা enforce করে, তাই ভুল দিক দিয়ে channel ব্যবহারের চেষ্টা করলে compile error হয়। Public API ডিজাইন করার সময় directional channel ব্যবহার করলে API contract অনেক বেশি স্পষ্ট হয়।

package main
import "fmt"
func ping(pings chan<- string, msg string) { pings <- msg }
func pong(pings <-chan string, pongs chan<- string) { pongs <- <-pings }
func main() {
    pings := make(chan string, 1)
    pongs := make(chan string, 1)
    ping(pings, "passed message")
    pong(pings, pongs)
    fmt.Println(<-pongs)
}

Select

কনসেপ্ট — What it is

select statement একাধিক channel অপারেশনের মধ্যে যেটা প্রথম ready হয় সেটা চালায় — একসাথে একাধিক channel এর উপর wait করার জন্য।

উদ্দেশ্য — Purpose

একাধিক channel সোর্স থেকে concurrently ডেটা হ্যান্ডেল করা।

কোথায় ব্যবহার — Where used

Multiplexing multiple goroutine result, timeout ইমপ্লিমেন্ট করা, cancellation হ্যান্ডেল করা।

🎯 Professional Note

default case সহ select non-blocking হয়ে যায় — কোনো channel ready না থাকলে সাথে সাথে default এ চলে যায়, এটা polling-এর মতো ব্যবহার করা যায় (তবে সতর্কতার সাথে, বেশি polling CPU নষ্ট করে)।

package main
import ("fmt"; "time")
func main() {
    c1 := make(chan string)
    c2 := make(chan string)
    go func() { time.Sleep(1 * time.Second); c1 <- "one" }()
    go func() { time.Sleep(2 * time.Second); c2 <- "two" }()
    for i := 0; i < 2; i++ {
        select {
        case msg1 := <-c1: fmt.Println(msg1)
        case msg2 := <-c2: fmt.Println(msg2)
        }
    }
}

Timeouts

কনসেপ্ট — What it is

select-এর সাথে time.After() combine করে কোনো channel অপারেশনের জন্য একটা maximum wait time সেট করা হয়।

উদ্দেশ্য — Purpose

একটা অপারেশন খুব বেশি সময় নিলে block হয়ে না থেকে গ্রেসফুলভাবে এগিয়ে যাওয়া।

কোথায় ব্যবহার — Where used

External API call, database query, দূরবর্তী worker-এর response wait করায়।

🎯 Professional Note

Production সিস্টেমে timeout ছাড়া কোনো blocking অপারেশন রাখা উচিত না — নাহলে একটা slow dependency পুরো সিস্টেমকে resource-starve করে ফেলতে পারে। context.WithTimeout আজকাল time.After-এর চেয়ে বেশি idiomatic কারণ এটা cancellation propagate করে।

package main
import ("fmt"; "time")
func main() {
    c1 := make(chan string, 1)
    go func() { time.Sleep(2 * time.Second); c1 <- "result" }()
    select {
    case res := <-c1: fmt.Println(res)
    case <-time.After(1 * time.Second): fmt.Println("timeout!")
    }
}

Non-Blocking Channel Operations

কনসেপ্ট — What it is

select-এ default case দিয়ে channel send/receive কে non-blocking বানানো যায় — channel ready না থাকলে সাথে সাথে default execute হয়, wait করে না।

উদ্দেশ্য — Purpose

কোনো channel অপারেশনের জন্য অপেক্ষা না করে immediately চেক করে এগিয়ে যাওয়া।

কোথায় ব্যবহার — Where used

Optional message check, polling loop, graceful degradation-এ।

🎯 Professional Note

Non-blocking check বেশি ব্যবহার করলে সাধারণত ভুল ডিজাইন সিগন্যাল — বেশিরভাগ ক্ষেত্রে blocking channel অপারেশন বা select with timeout-ই সঠিক সমাধান, non-blocking শুধু বিশেষ প্রয়োজনে।

package main
import "fmt"
func main() {
    messages := make(chan string)
    select {
    case msg := <-messages: fmt.Println("received", msg)
    default: fmt.Println("no message received")
    }
}

Closing Channels

কনসেপ্ট — What it is

close(ch) দিয়ে একটা channel বন্ধ করা হয়, যা বোঝায় আর কোনো ভ্যালু পাঠানো হবে না। বন্ধ channel থেকে receive করলে বাকি সব buffered ভ্যালু পাওয়া যায়, তারপর zero-value ও false (ok) পাওয়া যায়।

উদ্দেশ্য — Purpose

একটা producer জানানো যে সে সব ডেটা পাঠিয়ে শেষ করেছে, যাতে receiver জানতে পারে iteration কখন থামবে।

কোথায় ব্যবহার — Where used

range over channel শেষ করা, worker pool shutdown signal, pipeline completion।

🎯 Professional Note

বন্ধ channel-এ আবার send করলে panic হয়, এবং একটা channel দুইবার close করলেও panic হয় — সাধারণত শুধু sender বন্ধ করবে, receiver না। nil channel-এ send/receive চিরতরে block হয়ে থাকে (panic না, deadlock)।

package main
import "fmt"
func main() {
    jobs := make(chan int, 5)
    done := make(chan bool)
    go func() {
        for {
            j, more := <-jobs
            if more { fmt.Println("received job", j) } else {
                fmt.Println("received all jobs")
                done <- true
                return
            }
        }
    }()
    for j := 1; j <= 3; j++ { jobs <- j }
    close(jobs)
    <-done
}

Range over Channels

কনসেপ্ট — What it is

range keyword দিয়ে channel থেকে সরাসরি ভ্যালু iterate করা যায়; channel close না হওয়া পর্যন্ত এটা প্রতিটা ভ্যালুর জন্য অপেক্ষা করে, close হলে লুপ থামে।

উদ্দেশ্য — Purpose

একটা channel থেকে আসা সব ভ্যালু process করা এবং producer শেষ হলে স্বয়ংক্রিয়ভাবে থেমে যাওয়া।

কোথায় ব্যবহার — Where used

Streaming data processing, worker result collection।

🎯 Professional Note

যদি producer কখনো channel close না করে, তাহলে range লুপ চিরতরে block হয়ে থাকবে — এটা একটা কমন goroutine leak-এর কারণ, তাই producer side এ defer close(ch) প্যাটার্ন ব্যবহার করা ভালো অভ্যাস।

package main
import "fmt"
func main() {
    queue := make(chan string, 2)
    queue <- "one"
    queue <- "two"
    close(queue)
    for elem := range queue { fmt.Println(elem) }
}

Timers

কনসেপ্ট — What it is

time.NewTimer(d) একবার নির্দিষ্ট সময় পর একটা channel-এ ভ্যালু পাঠায়। time.Timer.Stop() দিয়ে সেটা বাতিল করা যায়।

উদ্দেশ্য — Purpose

একটা নির্দিষ্ট সময় পরে একটা কাজ ঘটানো, বা একটা পেন্ডিং কাজ বাতিল করার সুযোগ রাখা।

কোথায় ব্যবহার — Where used

Delayed job scheduling, request timeout ইমপ্লিমেন্ট করার নিচু-লেভেল building block।

🎯 Professional Note

package main

কোথায় ব্যবহার — Where used

WaitGroups

কনসেপ্ট — What it is

উদ্দেশ্য — Purpose

মেইন goroutine কে সব spawn করা goroutine শেষ হওয়ার আগে এগিয়ে যাওয়া থেকে আটকানো।

কোথায় ব্যবহার — Where used

Parallel task execution যেখানে result channel দরকার নেই, শুধু 'সব শেষ হয়েছে' নিশ্চিত করা লাগে।

🎯 Professional Note

wg.Add() সবসময় goroutine launch করার আগে call করুন, ভেতরে করলে race condition হতে পারে (Wait() আগে চলে যেতে পারে)। প্রতিটা goroutine-এর শুরুতেই defer wg.Done() করা নিরাপদ প্যাটার্ন, যাতে panic হলেও Done() call হয়।

package main
import ("fmt"; "sync")
func worker(id int, wg *sync.WaitGroup) {
    defer wg.Done()
    fmt.Printf("Worker %d done\n", id)
}
func main() {
    var wg sync.WaitGroup
    for i := 1; i <= 5; i++ {
        wg.Add(1)
        go worker(i, &wg)
    }
    wg.Wait()
}

কোথায় ব্যবহার — Where used

Mutexes

কনসেপ্ট — What it is

sync.Mutex একটা critical section-এ একসাথে একটা মাত্র goroutine ঢুকতে দেয় — Lock()/Unlock() দিয়ে shared state নিয়ে race condition এড়ানো হয়।

উদ্দেশ্য — Purpose

একাধিক goroutine যখন একই ডেটা পড়ে/লিখে, তখন data race রোধ করা।

কোথায় ব্যবহার — Where used

Shared cache, in-memory counter/map, কোনো shared struct-এর state আপডেট।

🎯 Professional Note

Lock() করার পর defer mu.Unlock() করা প্রায় বাধ্যতামূলক অভ্যাস — নাহলে কোনো panic বা early return এ unlock miss হয়ে deadlock হতে পারে। sync.RWMutex ব্যবহার করুন যদি read বেশি, write কম হয় — এটা একাধিক reader কে একসাথে চলতে দেয়।

package main
import ("fmt"; "sync")
type Container struct {
    mu sync.Mutex
    counters map[string]int
}
func (c *Container) inc(name string) {
    c.mu.Lock()
    defer c.mu.Unlock()
    c.counters[name]++
}
func main() {
    c := Container{counters: map[string]int{"a": 0}}
    var wg sync.WaitGroup
    for i := 0; i < 10; i++ {
        wg.Add(1)
        go func() { defer wg.Done(); c.inc("a") }()
    }
    wg.Wait()
    fmt.Println(c.counters)
}

উদ্দেশ্য — Purpose

🎯 Professional Note

এই প্যাটার্ন mutex-এর একটা বিকল্প, প্রতিস্থাপন না — ছোট, focused state-এর জন্য mutex সহজ ও যথেষ্ট। জটিল coordination logic দরকার হলে stateful goroutine প্যাটার্ন কোডকে বেশি readable করতে পারে।

package main
import "fmt"
type readOp struct{ resp chan int }
func main() {
    reads := make(chan readOp)
    state := make(map[int]int)
    go func() {
        for {
            read := <-reads
            read.resp <- state[0]
        }
    }()
    r := readOp{resp: make(chan int)}
    reads <- r
    fmt.Println(<-r.resp)
}

package main

        fmt.Println("overslept")
    case <-ctx.Done():
        fmt.Println("context done:", ctx.Err())
    }
}

        defer f.Close()

🎯 Professional Note

প্রতিটা incoming connection সাধারণত একটা আলাদা goroutine এ হ্যান্ডেল করা হয় (go handleConn(conn)) — এটা Go-কে concurrent সার্ভার লেখার জন্য খুব উপযুক্ত করে তোলে, কারণ প্রতিটা goroutine খুব সস্তা।

package main
import ("bufio"; "fmt"; "net")
func handleConn(c net.Conn) {
    defer c.Close()
    msg, _ := bufio.NewReader(c).ReadString('\n')
    fmt.Fprint(c, "echo: "+msg)
}
func main() {
    l, _ := net.Listen("tcp", ":9000")
    defer l.Close()
    for {
        conn, err := l.Accept()
        if err != nil { continue }
        go handleConn(conn)
    }
}

উদ্দেশ্য — Purpose

বর্তমান প্রোগ্রামের জায়গায় সরাসরি আরেকটা প্রোগ্রাম চালানো, যেমন Unix শেলের exec কমান্ডের মতো।

কোথায় ব্যবহার — Where used

Wrapper script/binary যেটা শুধু কিছু setup করে আসল টুলকে হ্যান্ড-ওভার করে দেয় (যেমন docker-entrypoint স্টাইল স্ক্রিপ্ট)।

🎯 Professional Note

Signals

কনসেপ্ট — What it is

os/signal প্যাকেজ দিয়ে OS সিগন্যাল (SIGINT, SIGTERM) একটা channel-এ ক্যাচ করা হয়, যাতে প্রোগ্রাম abrupt kill হওয়ার বদলে গ্রেসফুলি cleanup করে বন্ধ হতে পারে।

উদ্দেশ্য — Purpose

প্রোগ্রামকে external termination signal (Ctrl+C, container orchestrator stop) গ্রেসফুলভাবে হ্যান্ডেল করার সুযোগ দেওয়া।

কোথায় ব্যবহার — Where used

Graceful server shutdown, in-flight request শেষ করা, resource cleanup (DB connection close) — Kubernetes/Docker-এর সাথে কাজ করা প্রায় সব সার্ভিসে জরুরি।

🎯 Professional Note

Kubernetes pod বন্ধ করার আগে SIGTERM পাঠায় এবং কিছু grace period দেয় — সেই সময়ের মধ্যে signal.Notify দিয়ে সিগন্যাল ধরে ongoing request শেষ করে, নতুন connection নেওয়া বন্ধ করে, তারপর প্রোগ্রাম বন্ধ করা production-grade সার্ভিসের অপরিহার্য অংশ।

package main
import ("fmt"; "os"; "os/signal"; "syscall")
func main() {
    sigs := make(chan os.Signal, 1)
    signal.Notify(sigs, syscall.SIGINT, syscall.SIGTERM)
    done := make(chan bool, 1)
    go func() {
        sig := <-sigs
        fmt.Println("received signal:", sig)
        done <- true
    }()
    fmt.Println("awaiting signal")
    <-done
    fmt.Println("exiting gracefully")
}
